# معرفی ربات در تلگرام: ساندگیر

<div dir="rtl">

همه‌ی متن‌ها و عکس‌هایی که برای پروفایل ربات در [@BotFather](https://t.me/BotFather) لازم است. هر متن را از داخل بلوک کد کپی کنید. عکس‌ها با تم [میرزا](https://www.mirzaplugin.ir/) هستند، مثل [ربات حسابدار](https://github.com/IsAmirMmd/inline-calculator-telegram/tree/main/branding): زمینه‌ی کرم، کارت کاغذی با خط دور و سایه‌ی تخت مشکی، رنگ مرجانی و فونت وزیرمتن. آیکن یک ابر عمومی با فلش دانلود است، نه لوگوی ساندکلاد، تا ربات رسمی به نظر نرسد.

## ۱. اسم (Name)

دستور: `/setname`. همان اسمی که بالای چت دیده می‌شود. حداکثر ۶۴ کاراکتر.

**ساندگیر** یعنی «صدا را می‌گیرد»: کوتاه است، با «ساند» یاد ساندکلاد می‌اندازد و کار ربات را می‌گوید.

</div>

```
ساندگیر | دانلود از ساندکلاد 🎧
```

<div dir="rtl">

جایگزین‌ها: `ابرصدا 🎧 دانلود از ساندکلاد` (ترجمه‌ی تحت‌اللفظی SoundCloud) · `ساندلود | دانلود آهنگ ساندکلاد`

## ۲. About (بیو)

دستور: `/setabouttext`. روی صفحه‌ی پروفایل ربات دیده می‌شود. حداکثر ۱۲۰ کاراکتر.

</div>

```
🎧 لینک ترک ساندکلاد یا اسم آهنگ رو بفرست؛ چند ثانیه بعد فایل صوتی‌ش با اسم و کاور همین‌جاست. 👨‍💻 @isAmirMmd
```

<div dir="rtl">

جایگزین‌ها:

</div>

```
دانلود آهنگ از ساندکلاد، بدون اپ و بدون سایت. فقط لینک رو بفرست 🔗
```

```
🎧 ساندکلاد رو بیار توی تلگرام: لینک بده، آهنگ بگیر.
```

<div dir="rtl">

## ۳. Description

دستور: `/setdescription`. متنی که در چت خالی، قبل از «استارت»، زیر «What can this bot do?» می‌آید. حداکثر ۵۱۲ کاراکتر.

</div>

```
🎧 ساندگیر آهنگ‌های ساندکلاد رو برات می‌گیره و همین‌جا توی تلگرام می‌فرسته.

🔗 لینک ترک رو از اپ یا سایت ساندکلاد کپی کن (Share ← Copy link) و برام بفرست.
⚡️ چند ثانیه بعد فایل صوتی می‌رسه؛ با اسم، خواننده و کاور.
✏️ اسم، خواننده و کاورش رو هم با یه دکمه می‌تونی عوض کنی.
🔎 اسم آهنگ یا خواننده رو بفرست و از نتیجه‌ها انتخابش کن؛ توی چت‌های دیگه هم با نوشتن یوزرنیم ربات و اسم آهنگ.
✅ لینک‌های on.soundcloud.com و ترک‌های خصوصی با لینک مخفی هم قبوله.

👇 «استارت» رو بزن و اولین لینک یا اسم آهنگ رو بفرست.
```

آهنگی توی ساندکلاد پیدا کردی و می‌خوای همیشه دمِ دستت باشه؟ 🎧

۱. Share ← Copy link توی اپ ساندکلاد

## ۴. عکس پروفایل

دستور: `/setuserpic`. فایل را به‌صورت عکس بفرستید. یکی را انتخاب کنید (هر دو ۱۲۸۰×۱۲۸۰؛ تلگرام دایره‌ای برش می‌زند و همه‌چیز داخل دایره است):

| فایل | طرح |
|---|---|
| `bot-avatar.png` | ابر مرجانی با فلش دانلود، روی یک کلید کاغذی، زمینه‌ی کرم با نت‌های کم‌رنگ |
| `bot-avatar-coral.png` | همان با ابر مشکی، روی زمینه‌ی مرجانی (در لیست چت‌ها بیشتر به چشم می‌آید) |

## ۵. بنر (Description Picture)

دستور: `/setdescriptionpic`. عکسی که بالای Description در چت خالی نشان داده می‌شود.

- فایل: `banner.png` (۱۲۸۰×۷۲۰، نسبت ۱۶:۹). تلگرام آن را در گوشی حدود ۳۴۰ پیکسل عرض نشان می‌دهد، برای همین متن‌ها درشت‌اند.
- سمت راست اسم و کار ربات است. سمت چپ لینکی است که کاربر می‌فرستد و فایل صوتی‌ای که برمی‌گردد. اسم ترک و خواننده‌ی روی کارت ساختگی‌اند.

## ۶. دستورها (Commands)

لازم نیست دستی تنظیم شوند: هر دیپلوی و `/start` ادمین آن‌ها را با `setMyCommands` می‌فرستد (`syncCommands` در `tgcloud/lib/admin.js`). برای همه:

</div>

```
start - شروع و منوی ربات
help - راهنمای دانلود از ساندکلاد
```

<div dir="rtl">

## ۷. ترتیب پیشنهادی در BotFather

1. `/mybots` و انتخاب ربات ← **Edit Bot**.
2. **Edit Name** ← متن بخش ۱. **Edit About** ← بخش ۲. **Edit Description** ← بخش ۳.
3. **Edit Description Picture** ← `banner.png`. **Edit Botpic** ← یکی از عکس‌های بخش ۴.

## ۸. تنظیمات دیگر

- **Inline mode** (جستجو در هر چت با `@SoundCoudMusicBot اسم آهنگ`، `tgcloud/lib/inline.js`): دو تنظیم، هر دو در **Bot Settings**:
  - `/setinline` ← روشن، با این متن راهنما (placeholder):

</div>

```
اسم آهنگ یا خواننده…
```

<div dir="rtl">

  - `/setinlinefeedback` ← **100%**. با این، آهنگی که تازه است بلافاصله بعد از انتخاب، خودش جای پیام «⏳» می‌آید. بدونش باید روی دکمه‌ی «⏳ در حال آماده‌سازی…» زد.
- **Groups:** ربات فعلاً فقط در پی‌وی جواب می‌دهد. می‌شود `/setjoingroups` را روی `Disable` گذاشت تا وقتی گروه‌ها اضافه شوند.
- **Serverless → CLI Access → Access token:** توکن `tgcloud login` و سکرت `TGCLOUD_TOKEN` در GitHub. در چت یا کد نگذارید.
